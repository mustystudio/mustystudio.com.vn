# MUSTY STUDIO — Website nhiều trang

## Cấu trúc
- `index.html` — Trang chủ
- `about.html` — Giới thiệu
- `products.html` — Sản phẩm
- `blog.html` — Bài viết
- `contact.html` — Liên hệ
- `collections.html` — Bộ sưu tập
- `style.css` — Giao diện
- `script.js` — Chức năng website

## Cách đưa lên GitHub Pages

1. Mở repository GitHub `mustystudio.github.io`.
2. Chọn Add file → Upload files.
3. Upload 8 file HTML, CSS và JavaScript vào thư mục gốc.
4. Giữ nguyên thư mục images hiện tại.
5. Nhấn Commit changes.
6. Đợi GitHub Pages cập nhật website.

## Các ảnh cần có trong thư mục images

- images/musty-hero.jpg
- images/product11.jpg
- images/product2.jpg
- images/product3.jpg
- images/product4.jpg

Nếu thiếu product4.jpg, hãy đổi đường dẫn ảnh trong index.html và products.html sang tên ảnh thực tế.

## Việc cần chỉnh trước khi công khai

- Trong script.js, thay hello@mustystudio.com bằng email nhận đơn thật.
- Kiểm tra lại giá sản phẩm và ảnh.
- Nội dung blog hiện là nội dung mẫu, có thể thay bằng bài viết thật.

## Lưu ý

Website tĩnh trên GitHub Pages không tự lưu đơn hàng vào cơ sở dữ liệu. Giỏ hàng hiện hoạt động trong phiên trình duyệt; nút liên hệ mở ứng dụng email để gửi yêu cầu.
